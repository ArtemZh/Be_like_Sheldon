# Куди доїду за день

Куди можна з'їздити потягом по Німеччині туди-назад у понеділок
(виїзд після 09:00, повернення до 23:00) — і скільки корисних годин
лишиться на місці.

Метрика — не час у дорозі, а **корисний час на місці**: вікно між приїздом
і останнім потягом назад, мінус година на вокзал, каву й хотдог.

## Як воно влаштоване

Передрахунку відповідей немає. Збірка перетворює GTFS на компактний
бінарний розклад (4.7 МБ, 1.7 МБ у gzip), браузер завантажує його один раз
і рахує RAPTOR у Web Worker — 10–40 мс на запит. Тому стартом може бути
**будь-яка** з 7737 станцій, куди клікнеш на карті.

Пітонівська реалізація RAPTOR лишається еталоном: обидві ганяються на тій
самій фікстурі, а на справжньому фіді результати звіряються числом у число
(`tools/crosscheck.mjs`).

## Мови

Інтерфейс перекладено на англійську, німецьку, польську й українську;
за замовчуванням англійська, вибір запамʼятовується в браузері. Усі рядки
лежать у `web/src/i18n.js`, тест перевіряє, що набори ключів у мовах
збігаються.

## Ілюстрація

`web/public/intro.webp` — кадр із серіалу, а не матеріал проєкту: на нього
не поширюється ліцензія репозиторію. Якщо публікуєте сайт, це варто мати
на увазі; без файлу вступне вікно просто обходиться без картинки.

## Збірка даних

1. Завантажити GTFS-фід у `gtfs/db.zip`. Джерела (gtfs.de, CC-BY 4.0):
   - регіональні потяги, 12 МБ: `https://download.gtfs.de/germany/rv_free/latest.zip`
   - усе разом з ICE, 272 МБ: `https://download.gtfs.de/germany/free/latest.zip`
2. Зібрати:

```bash
python3 -m venv .venv && .venv/bin/pip install -e '.[dev]'
.venv/bin/python -m build.cli gtfs/db.zip --out web/public/data
```

Займає секунд десять. На виході `feed.bin`, `feed.meta.json`,
`stations.json` і `network.json`.

Безкоштовні фіди покривають лише найближчі тижні, тож дані треба
перезбирати.

## Тести

```bash
.venv/bin/pytest              # швидкі, на фікстурному фіді
.venv/bin/pytest -m slow      # на справжньому фіді, потребує gtfs/db.zip
cd web && npm test            # фронтенд і JS-роутинг
node tools/crosscheck.mjs     # звірка JS проти Python на справжньому фіді
```

## Фронтенд

```bash
cd web && npm install && npm run dev
```

# Куди доїду за день

Три режими на одній карті Німеччини:

- **Куди доїду** — куди можна з'їздити потягом туди-назад у понеділок
  (виїзд після 09:00, повернення до 23:00) і скільки корисних годин
  лишиться на місці. Метрика — не час у дорозі, а **корисний час на
  місці**: вікно між приїздом і останнім потягом назад, мінус година на
  вокзал, каву й хотдог.
- **Маршрут Шелдона** — розказана карта: поїздка з «Дитинства Шелдона»
  трьома маршрутами, де текст і карта керують одне одним.
- **Скрінсейвер** — розклад одного понеділка в русі: станції світяться,
  коли на них стоїть потяг, а табло по черзі показує живий рейс і факт про
  німецьку залізницю.

## Як воно влаштоване

Передрахунку відповідей немає. Збірка перетворює GTFS на компактний
бінарний розклад (4.7 МБ, 1.7 МБ у gzip), браузер завантажує його один раз
і рахує RAPTOR у Web Worker — 10–40 мс на запит. Тому стартом може бути
**будь-яка** з 7737 станцій, куди клікнеш на карті.

Пітонівська реалізація RAPTOR лишається еталоном: обидві ганяються на тій
самій фікстурі, а на справжньому фіді результати звіряються числом у число
(`tools/crosscheck.mjs`).

## Карта

Підкладка своя: один GeoJSON із межами шістнадцяти земель, а колії й
станції малює сам застосунок. Усе поза Німеччиною на карту не потрапляє.
Друга підкладка (CARTO) лишилась на перемикачі — коли потрібен контекст:
дороги, міста, сусідні країни.

## Мови

Інтерфейс перекладено на англійську, німецьку, польську й українську;
за замовчуванням англійська, вибір запамʼятовується в браузері. **Усі
тексти — у `web/src/strings.js`**: ключ і чотири мови поруч, включно з
фактами, розповіддю та екскурсією. Тести перевіряють, що в кожного ключа
є всі мови й що плейсхолдери в них збігаються.

## Джерела

Кнопка «Джерела» в правій панелі відкриває повний список: фід, геометрія
країни, пішохідний маршрут, підкладки, шрифти й усі статті Вікіпедії, з
яких зібрані факти.

Двох кадрів із «Дитинства Шелдона» (`web/public/intro.webp`,
`sheldon.webp`) у репозиторії немає: права на серіал належать студії.
Вступне вікно й сторінка розповіді працюють без них — якщо покласти файли
поруч локально, вони підхопляться.

MIT покриває код. Дані лишаються під своїми ліцензіями: розклад gtfs.de —
CC BY 4.0, межі земель — dl-de/by-2-0, пішохідний маршрут — ODbL
(OpenStreetMap), тексти фактів — CC BY-SA 4.0, бо переказують статті
Вікіпедії.

## Дані

**Дані вже в репозиторії.** `web/public/data/` (11.2 МБ) — зібраний
знімок розкладу на понеділок 2026-08-31 із фіду `rv_free`. Клонуєш,
запускаєш `npm run dev` — усе працює: ні Python, ні походу на gtfs.de для
цього не треба, і CI теж нічого не збирає.

Ціна такого рішення — дані не оновлюються самі. Безкоштовні фіди
покривають найближчі тижні, тож колись розклад доведеться перезбирати
скриптом нижче; поточна версія сайту працює на зафіксованому знімку.

### Як перезібрати

1. Завантажити GTFS-фід у `gtfs/db.zip`. Джерела (gtfs.de, CC-BY 4.0):
   - регіональні потяги, 12 МБ: `https://download.gtfs.de/germany/rv_free/latest.zip`
   - усе разом з ICE, 272 МБ: `https://download.gtfs.de/germany/free/latest.zip`
2. Зібрати:

```bash
python3 -m venv .venv && .venv/bin/pip install -e '.[dev]'
.venv/bin/python -m build.cli gtfs/db.zip --out web/public/data
```

Займає секунд десять. На виході `feed.bin`, `feed.meta.json`,
`stations.json`, `network.json` і `patterns.json` — плюс збірка
перезаписує `web/src/story-paths.js` (лінії маршруту Шелдона по справжніх
станціях), бо вони мають лишатись узгодженими з мережею.

Пішохідний маршрут Вайнгайм — Гейдельберг у `web/src/walk-route.js`
прокладено один раз через OSRM і збережено в код — він не залежить від
розкладу:

```bash
curl -s 'https://router.project-osrm.org/route/v1/foot/8.66552,49.55332;8.67583,49.40393?overview=full&geometries=geojson'
```

Деплой на GitHub Pages збирає дані сам: workflow качає свіжий `rv_free`,
проганяє `build.cli` і тести, і лише тоді будує сайт.



## Тести

```bash
.venv/bin/pytest              # швидкі, на фікстурному фіді
.venv/bin/pytest -m slow      # на справжньому фіді, потребує gtfs/db.zip
cd web && npm test            # фронтенд і JS-роутинг
node tools/crosscheck.mjs     # звірка JS проти Python на справжньому фіді
```

## Фронтенд

```bash
cd web && npm install && npm run dev
```
